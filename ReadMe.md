# 2SS

2SS is a new style of Nystrom sampling by using two landmark sets, a large set and a small-but-optimized one. 2SS improves the approximation accuracy without additional embedding time cost, hence is suitable for large-scale kernel approximation where embedding time cost is the bottleneck. 2SS is easy to be plugged-into a Nystrom method to improve the embedding accuracy. We also provide the Python version which has been verified in MindSpore.

Run **demo.m in Matlab** or **main.py in Python/MindSpore**

[1] Li He and Hong Zhang, Two-Step Nystrom Sampling for Large-scale Kernel Approximation, to appear in IEEE Transactions on Big Data
